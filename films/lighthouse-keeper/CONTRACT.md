# 守灯人：制作约定

一支 70 秒的手绘风动画短片，2048×1152，24 帧，1680 帧。画面和声音全部由代码生成：不用图片模型，不用图片、字体和采样素材，每个随机种子都固定。目标是看起来像一部完成了的剧场版日本动画（吉卜力那一路）：水粉背景、赛璐珞角色、真正的动画节奏。

没有人物。主角是一只小水獭，它是孤岛灯塔的守灯人。

## 故事

海上孤岛的灯塔里，小水獭每晚给灯上油、擦镜片。风暴夜，窗被吹开，灯灭了，一条渔船在雾和浪里迷了方向，正朝礁石开去。水獭用身子顶住窗、护住火柴，重新点亮了灯，光柱扫过海面，渔船转舵避开礁石。清晨，风平浪静，渔船从塔下经过，鸣笛两声道谢，水獭在栏杆边挥了挥爪子。

情绪曲线：安静、温暖 → 不安 → 黑暗和紧张（一拍完全的静止）→ 爆发（光重新亮起）→ 壮阔（光柱）→ 温柔收尾。

## 色彩脚本（守住它：一部片子，一个画家）

- **s1 夜**：天 `#121a3a → #1f2b5a → #3a4a85 → #6a6fa8`，海平线上一丝冷青。月光下的云 `#c7cfea / #8f9acb / #5a66a6 / #2c3670`。海 `#0f1838 / #22305e`，月光碎银 `#cfd8ff`。塔身石头 `#9aa0c8 / #5c6394 / #343a66`，红带 `#8e3a44 / #5a2a3c`，绿铜 `#78a8a4 / #3f6f7d / #2b4a63`。唯一的暖光 `#ffc46b`，光柱 `#fff0c8`（很淡，靠雾显形）。
- **s2、s3、s7 灯室**：永远不是纯黑。暗部 `#1c1a30`，环境 `#2c2a48`。灯光琥珀 `#ffb458`，衰减短。黄铜 `#c8963c / #8a6130 / #4a3226`，木头 `#6a4b3c / #463239 / #2b2233`，墙在暗处 `#8a7f9c`，窗外夜色 `#26305e`。
- **s4、s6、s8 风暴**：天 `#2a2e3e → #454a5c → #6b6f7e`（偏冷的灰绿），云 `#8c90a0 / #5a5e70 / #33374a`，海 `#1c2a33 / #2f4452`，浪沫 `#d8e2e6`，雨 `#a8b6c4`，闪电 `#e8f0ff`，光柱 `#fff2d0`，马灯 `#ffc070`。
- **s5 灯灭**：环境 `#141a2a`，窗外风暴光 `#5a6a8a`，闪电时整屋一亮 `#c8d4f0`。
- **s9 黎明**：天 `#8fb6d9 → #e9c6c8 → #f7d9a8 → #ffe7b8`，太阳 `#fff3d6`，海 `#9aa8c8 / #c7b6c4`，碎金 `#ffe2a8`，石头 `#e6d0b8 / #b89a9c / #8d7a98`，栏杆铁 `#4a4058`。

阴影永远带颜色（紫、玫瑰、蓝），不用灰和黑。柔和、自然、略低对比的广告色。不要霓虹、不要青橙、不要 HDR。

## 灯塔的光学（室内室外同一套）

只有一座灯塔、一套透镜：灯焰不动，外面的菲涅耳透镜在转。透镜上有 **2 块牛眼**，所以从外面看是一前一后两道光束；透镜 **8 秒转一圈**（`lighthouse.BEAM_PERIOD`）。转角按全片时间算，切镜头时连续：室外用 `lighthouse.beam_az(t)`，室内用 `lamproom.lens_rot(镜头号, f)`，两者都从同一个周期来。灯灭了，钟表机构照转，只是没有光束；s7 点灯前守灯人把机构停住（检修门对着它），光绽开后再起转到 8 秒一圈。在灯室里要看得出它在转：牛眼一块块从眼前转过，光束扫过墙和窗。

## 主角：水獭

小水獭（欧亚水獭），站起来约 40 厘米。背和四肢 `#7a5236`，暗部 `#4e3226`，受光 `#a8784e`；脸、下巴、胸口奶油色 `#e9d6b8`，暗部 `#b89c86`；鼻头 `#2a1e22`；圆圆的小耳朵；长胡须；大而黑的眼睛带一颗高光；蹼爪；粗、往尾尖收的尾巴。脖子上一条小小的针织红围巾 `#b8443c / #7e2a30`，这是它的标记。设计简单、可爱、轮廓清楚，从每个角度都不走样。

## 画面

**背景**：纸上的水粉广告色。先画三到五块大的明暗（眯眼测试），再一样一样地画：每块石头、每片浪、每团云、每块砖都是单独的一笔，有自己的颜色。剪影边缘清楚，阴影和雾里的边缘消失。笔触顺着形体走（顺着浪、绕着云团、顺着木板），不是一层全局的纹理。留出安静的区域，不要满屏一样大的笔触。层次之间有空气。构图偏一侧，消失点在画面宽度的 55–65%。

**赛璐珞**（水獭、船、会动的道具）：平涂底色 + 一块硬边阴影 + 可选的受光边，用暖深色的线描边（1.6–3.2 像素，有压力变化，两头收尖，在铅笔会抬起的地方断开）。角色上不用柔和渐变。每一张画给控制点 0.3–0.8 像素的抖动（`boil`，以画的序号为种子）。

**光**：光把角色和背景统一起来。灯要把地板、黄铜、墙和水獭都染暖；闪电要同时照亮云、浪和塔；光柱靠雨和雾显形。

**动作**：一拍二、一拍三（`d = f // 2` 或 `f // 3`），关键姿势和停顿，预备动作，最快的几张用拉长的画（带干笔速度线），跟随和重叠动作（毛、围巾、尾巴、草、雨）。镜头一拍一，慢。不要漂、不要一直晃、不要网页式的缓动、不要整块平移的图层。

**合乎物理**：往哪儿走就朝哪儿；抓着、推着、拿着的地方真的碰着；船随浪面的坡度俯仰；雨和浪沫受同一个风向；光和影子来自同一个光源。镜头移动时画框四边永远铺满。

**绝不能像**：3D 或 CG 质感、矢量图、一样粗的描边、完美的椭圆和直尺线、粒子系统、复制粘贴（没有两块石头、两朵浪、两朵云一样）、脏颜色、看起来没画完的空白、合成的条纹噪点、HDR 光晕。

## 镜头模块接口：`films/lighthouse-keeper/shots/<type>.py`

```python
import sys, os
from lp import W, H, comp, cache_path   # 驱动已把 verticals/anime 和片子目录放进 sys.path

class Shot:
    n = 168                                # 帧数，片内 f = 0..n-1；必须等于 film.json 里的时长 × 24
    finish = dict(hal_amt=.22, vig=.10)    # comp.finish 的参数，由驱动施加；颗粒和光学不要自己做
    cues = []                              # 可选：密集的小动作给声音用 [('step1', 0.5, 'step', {})]，秒数是镜头内的
    def setup(self): ...                   # 只画一次的底版；用 cache_path('s1_sky_v3.npy') 存 float16，名字里带版本号
    def frame(self, f): ...                # -> float32 (1152, 2048, 3) 显示空间 RGB，光烧亮的地方可以超过 1
    def actors(self, f): ...               # 可选，见下文“检查”
```

- 驱动会在 `setup()` 之前设好 `self.scene`：这个镜头在 `film.json` 里的那一项，事件时刻从 `self.scene['events']` 读。
- 一帧必须只由 `f` 决定（不在两帧之间留状态），帧会并行渲染。种子固定。
- 一帧的 CPU 时间不超过 3 秒（目标 1 秒）。`setup()` 第一次画板可以慢，之后从缓存读要快。
- 淡入淡出由驱动按 `film.json` 的 `fadeIn`、`fadeOut` 做，镜头里不要自己做。

## 水獭的接口

`films/lighthouse-keeper/otteract.py` 归水獭线所有：

```python
img = otteract.draw(img, key, f, M)       # 把水獭画进 img；key 是镜头号（'s2'），f 是镜头内帧号
acts = otteract.actors(key, f, M)         # 这一帧水獭的位置报告，给检查用
```

`M` 是镜头给出的“标记”（画面像素）：至少有 `ground`（脚下地面的 y）、`x0`、`x1`（它在这个镜头里活动的范围）、`scale`（站立时的像素高度）、`light`（`dict(dir=(dx,dy), color='#ffb458', amt=.8)`，主光从哪边来），镜头需要的其他位置（梯口、油槽、窗、火柴、栏杆）也写在 `M` 里。`M` 写成镜头类的常量 `Shot.M`，水獭线会读它。

水獭线做完之前，`otteract.draw` 画一个灰色的替身，方便各条线判断比例。脚下的接触阴影、灯光照在背景上的部分归镜头；赛璐珞本身归水獭线。别在水獭头后面画重要的东西。

## 检查

片子会跑 DreamFactory 管线的自检。和画面有关的几项：

- `actors(f)` 返回 `[dict(name='水獭', x=, y=, s=, facing='right'|'left', points={...})]`，规则和叙事片一样：`x, y` 是地面上的位置，`facing` 是正侧面画时的朝向；四分之三侧面或正面时不写 `facing`。道具加 `prop=True`。抛出去的东西加 `air`（离地像素）和 `ballistic=True`。接触点写在 `points` 里，用画面像素。
- `pops`：剪辑点、淡入淡出和声明过的事件以外，画面没有一帧突然跳变（闪电要在 `events` 里声明，`s4.lightning`、`s3.flash`）。
- `palette`：每个镜头整体颜色符合色彩脚本。
- `cue-sync`：每个声明的事件都有声音，起点对准。

## 质检（每条线都必须做）

1. `python -m py_compile`，然后用读取工具看自己的画面：整帧，加上至少三处 1:1 局部（`--crop x,y`，实际像素 600×450），至少 6 个不同的帧。
2. 老实写下最不像剧场版吉卜力画面的三处，改掉。至少 4 轮。每轮都做眯眼测试：有没有 3–5 块清楚的明暗？
3. 看连续帧（`--sheet`，比如 60 62 64 66 68 70），不只看静帧。
4. 一张静帧放在一臂之外能当成一部电影里的一帧时停下，或者大约 8 轮后停下。

质检图用 JPEG，每条线最多约 60 个文件，旧的删掉。不要留着后台进程。机器只有 4 个核、15 GB 内存，几条线共用：渲染最多 `--jobs 1`（单个镜头预览视频最多 `--jobs 2`），`cv2.setNumThreads(2)`，缓存用 float16，不要长期持有巨大的数组。
