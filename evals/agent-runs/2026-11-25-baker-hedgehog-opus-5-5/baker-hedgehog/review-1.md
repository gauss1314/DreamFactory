# 审片意见

我把三个镜头都看完了：19 张全景，加上远景、颠簸、回头、鸽子落地这几处的 1:1 局部（时刻都按 frames.md）。按严重程度排，退回重做的有 8 处。

1. **面包往镜头这边掉，不在路上（必须改）**：full-08（7.05s）里面包从车厢中部弹起，可落地点在 (775, 960)。车轮和刺猬脚踩的地面线在 y≈885，面包比它低了约 75px。也就是说面包是往镜头这边飞的，但大小没有按透视变大。落地后也没有弹一下、滚一下；到 full-09 它只是随镜头平移，不在车辙后面的路上。
2. **刺猬鼻子顶在车厢上（必须改）**：full-04 到 full-09、full-11、full-19 都是这样。最清楚的是 near-06：鼻尖 (565, 730) 正好贴在车沿左端，美术规范第四节明确说这是错的。前爪握的把手也只是一截短棍，插在车厢底角上，看不出是车的一部分。
3. **远景里烟囱的烟几乎看不见（必须改）**：简报写了"屋顶上的烟囱冒着烟"。full-01、full-03 的烟囱顶上只有 (640, 480)、(1070, 540) 附近几缕近乎透明的白雾，眯眼就没了。这个镜头下面三分之一是一样大小的石板，刺猬小到快找不着。房子是平的矩形，窗户排成整齐的格子，云彩带一圈错开的紫边，像矢量贴图。
4. **颠簸读不出来**：full-05（6.50s）那块"凸起的石头"是一颗扁平的小卵石，还被前轮挡着，看不出它把车顶起来。到 full-06，车身一歪，面包飞了，可刺猬的姿势和帽子跟 full-05 一模一样，身体没有一顿、一弹、再落下。
5. **整片没有投影**：太阳在画面右侧（full-08 约 (1760, 450)），可刺猬、车轮、面包、鸽子脚下都没有朝左、朝前的投影，角色身上也没有朝向太阳的受光边。只有刺猬脚下有一小片看不清形状的紫色，于是车像浮在石板上。
6. **回头时脸像贴在背上**：full-14、near-14（10.50s），回头的脸画在刺球中间，鼻子从背上的刺里伸出来，两只手还朝右握着把手。读起来像背后长了一张脸，而不是转过头去。
7. **鸽子的翅膀像尾巴**：full-11、near-11-鸽子（10.00s，落地那一刻），只有一只翅膀竖在背后，又宽又直，看着像松鼠尾巴，不像刚收翅落地的鸽子。另一只翅膀和收翅的动作都没画。
8. **刺猬定格在跨步上**：full-11、13、14、17（10.00 到 11.20s），刺猬和车的位置一像素都没动，背景也没动，腿却一直停在同一个跨步上，车轮也不转。停下来回头本身可以，但应该换成站定的姿势，回完头再起步。
