# 审片意见

我会退回去重做 8 处。最严重的两处：简报里写的按车铃，画面上根本没有；前轮压石子时，轮胎直接穿过了石头。

**必须改（违反物理或简报）**

1. **车铃没画出来，也没有按的动作**（full-11 / full-14，10.90 秒和 11.25 秒）。车把上只有一个灰色的翼尖压在握把上，车上任何地方都找不到铃。对比 near-11 和 near-14，两个“按铃”时刻的姿势和 10.90 秒时一模一样。观众看不出它按了铃，后面白鹭惊飞就没有起因。
2. **前轮压石子时，轮胎穿过了石头，车也没被顶起来**（full-05 / full-06，7.50 秒和 7.70 秒）。7.50 秒时，石子（约 x 975, y 895）已经嵌进前轮前下方的轮圈里。7.70 秒时，石子（约 x 890, y 895）整块落在前轮里，压在轮胎下面。这时鹈鹕的头抬高了约 15px，但两个车轮底边都还在 y≈900，前轮没有离地，车身也没有前倾。结果是身体自己弹了一下，车却没碰到石头。对比 full-09（8.22 秒），过石子时后轮被抬起来了，说明后轮那次是对的，前轮这次没做。
3. **喉囊没有跟随晃动**（full-04、05、06、08、09）。简报要求喉囊随颠簸晃动。实际上这几张里喉囊的形状完全一样，只是跟着头整体上移。颠簸后 0.2 秒（full-06、full-09），喉囊既没有滞后也没有往下甩。

**改了会明显更好**

4. **影子方向不对，角色上也没有受光边**（full-04 到 full-10、full-18）。太阳在画面右侧背景里，低悬，是逆光。车下的影子却是一团又短又圆的紫色，正好在车的正下方。它应该是一条长影，朝镜头方向、往左下拉出去。鹈鹕的暗部也都在身体下侧，朝太阳那一侧（右边，背和颈）没有暖色受光边，角色和背景没被同一束光统一起来。
5. **飞起来的白鹭贴住了鹈鹕的后脑**（full-18，12.75 秒）。约 x 880, y 620 处有一只飞着的白鹭，叠在鹈鹕冠羽和后脑上，看起来像撞在一起。白鹭群里的每只鸟都是同一个白色叶片形，大小、姿态几乎一样，违反了“每只鸟都不一样”。
6. **远景下半屏是空的，而且看不出是“河堤”**（full-01 / full-03）。y 800–1000 是一整块均匀的黄绿色，没有明暗块，也没有顺着坡的笔触。堤顶的路只是一条细带，后面紧贴着河，没有坡面，看不出这是堤顶。鹈鹕只占约 80px 高，四周没有任何东西把视线引过去。
7. **背景像贴纸和矢量图，而不是水粉**（所有 full 图）：
   - 对岸的城市是一排纯色矩形，加上同样的小亮点窗。
   - 芦苇都是同一种直杆加顶部一簇放射线（full-04 下方一排最明显），粗细和弯度都差不多。
   - 云都是硬边的两层色块，暗部做法是整块错位一下。
   
   这些都没有笔触，层次也平。
8. **第二镜里切出来的 1:1 局部框没跟住鹈鹕**（near-04、near-06）。框里只有石子、路面和芦苇，看不到鹈鹕。这些角度没法核对脚和踏板、翼尖和车把是不是真的碰着。按美术规范第六节，至少要能看清三处角色的 1:1 局部。
