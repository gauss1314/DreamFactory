# 审片意见

我把 13 张全景和其中 6 张局部逐张看完了。整体问题：简报里两个关键动作没有画清楚，一个是投信，一个是“暖光落在它身上”；乌龟身上一处投影都没有；第一镜和第二镜里的“桥”对不上。共 8 条，按严重程度排序：

1. **路灯的光没照到乌龟（full-11 / full-12，9.0–10.2 秒）**：灯头在画面 x≈1090，地上的光斑在 x≈1070 一带。乌龟在左边 x≈600–880，完全在光外面。near-12 里龟壳和脸跟亮灯前一样是冷紫色，身上没有暖色受光边。简报写的“暖光落在它身上”没有画出来。
2. **投信看不见，信封也塞不进去（near-05 → near-06 / full-06，6.2 → 7.0 秒）**：6.2 秒信还横叼在嘴里，脖子是缩着的。到 7.0 秒投信这一刻，脖子已经伸长，信却不见了，中间没有一张画出信插进口子。另外，投信口是邮筒左侧面上一条又窄又竖的缝，信封横着放比它宽，这样是投不进去的。
3. **光锥和地上的光斑断开了（full-11 / 12 / 13）**：灯下那块三角形的光锥往下只画到远处堤墙（y≈750）就停了，还叠在对岸的房子和水面上，看起来像在照远处。近处石板路上没有光锥，只在 y≈1000 有一块孤立的椭圆光斑，两者接不上。
4. **全片没有投影**：乌龟、邮筒、路灯脚下都没有影子或接地的暗部。第一、二镜太阳在正前方低处逆光，影子应该朝镜头这边拉长（full-01、full-04）；第三镜灯亮以后，乌龟的影子应该落在离灯远的左边（full-12）。现在乌龟像贴在石板上的贴纸。
5. **桥前后对不上（full-01 / full-02 / full-04）**：第一镜的桥在对岸，是一块平板，下面一个深色半椭圆当桥洞。这个半椭圆的下沿压到了水面以下（y≈600），而且全片只有这座桥在水里没有倒影。第二镜的“桥”却成了近岸一段砖砌的坡道，第一镜的近岸根本没有桥，“走到桥边的邮筒”在空间上说不通。
6. **第二、三镜之间跳色（full-08 → full-09）**：7.4 秒太阳还明显挂在地平线上方，天是暖金色。8.8 秒太阳整个没了，天一下变成灰紫，对岸的房子也全换了一套。这违反美术规范“镜头之间不能跳色”。
7. **背景像矢量插画（full-01 / full-04 / full-09）**：房子是平涂的矩形，窗户排得整整齐齐。云的底边被平着切断，看起来是同一种形状。石板路铺满大小一样的椭圆，越往近处也不变大，没有透视。第一镜下半屏是大片一样的碎石，没有大的明暗块，也没有留白的安静区域。
8. **路灯杆像插在地上（full-11 / near-12）**：灯杆下端收成一个尖，直接扎进石板缝，没有灯座。
